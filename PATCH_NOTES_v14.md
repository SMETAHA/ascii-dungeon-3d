# v14 — Modern UI / GUI Rework

- Полностью переделаны главное меню, настройки, HUD, Game Over и инвентарь.
- Добавлены стеклянные панели, rounded-cards, chips, цветовые акценты, status bars.
- HUD стал компактнее: здоровье, опыт, cooldown атаки, статы и экипировка вынесены в читаемые карточки.
- Инвентарь получил современную двухпанельную раскладку: список предметов слева, подробности/статы справа.
- Добавлены фильтр-чипы, scrollbar списка, нормальное контекстное меню и аккуратные сравнения статов.
- Тосты/сообщения теперь появляются сверху в красивой карточке, а не простой строкой снизу.
