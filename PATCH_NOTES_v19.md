# v19 — feel / responsiveness pass

- Player movement now uses crisp acceleration/friction instead of direct frame displacement.
- Default player speed increased; saved settings still apply.
- Attacks are faster and more forgiving: wider melee cone, longer input buffer, hold-to-attack kept.
- Added hitstop and screen shake on hits.
- Added enemy knockback and player knockback on damage.
- Enemies now use steering velocity instead of instant sliding.
- Enemy groups separate from each other and should stack less.
- Enemy attack pacing tuned down a bit to feel less sticky/unfair.
- Crosshair turns green when an enemy is actually in attack range/line of sight.
