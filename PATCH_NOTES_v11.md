# ASCII Dungeon 3D v11

Gameplay/balance pass:

- Reworked player/enemy damage formulas. Armor is now percentage mitigation instead of flat subtraction.
- Added dodge/miss, crit normalization and safer stat caps.
- Rebalanced enemy level, HP, damage, defense, aggro and XP by depth/player level.
- Reworked loot generation: item level, rarity curves, power scaling, normalized percent stats, powerScore.
- Improved attack logic: melee cleave, ranged narrow hit, line-of-sight check, distance falloff.
- Improved level progression and stat growth.
- HUD now shows compact combat stats and last combat event.
- Chests now generate properly scaled loot.
